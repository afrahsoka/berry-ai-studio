# Berry AI Studio v0.2 — Free-first

## مبادئ النسخة
- لا اشتراكات مدفوعة.
- لا شراء Credits.
- لا مفاتيح API مدفوعة أو ربط تلقائي بخدمة فوترة.
- لا تحويل تلقائي إلى مزود مدفوع.

## الميزات
- Prompt Studio للصور والفيديو.
- كتالوج روابط إلى Hugging Face Spaces حسب نوع النموذج (Text-to-Image و Text-to-Video). توفر المساحات المجانية وحدودها تتغير، ويجب التأكد من شروط كل Space قبل الاستخدام.
- معاينة فيديو وفلاتر عرض داخل المتصفح.
- دمج فيديوهات تجريبياً عبر FFmpeg.wasm.

## حدود مهمة
هذا التطبيق لا يحتوي على محرك توليد صور/فيديو محلي مدمج. التوليد يتم داخل Space خارجي تختارينه يدوياً، لذلك لا نضمن توفره أو سرعته أو مجانيته الدائمة. لا تدخلي بطاقة بنكية ولا تشترِي Credits. إذا طلبت الخدمة دفعاً، أغلقيها.
- دمج الفيديو قد يكون ثقيلاً على Android، خصوصاً مع ملفات كبيرة.
- هذه نسخة PWA وليست APK أصلياً.
- لا توجد API keys داخل ملفات التطبيق.
